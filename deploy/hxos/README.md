# HXOS deployment overlay

This directory is reserved for HXOS-owned deployment metadata only. It must not modify Activepieces Community Edition source code or copy Enterprise-only code.

The first deployment target is a managed container platform using the official Activepieces Community Edition image/template with persistent Postgres and Redis, HTTPS, and host-managed secrets. The owner requested a no-shell workflow.

Do not place credentials in this directory.
